ElGamal Encryption
Every vote is encrypted the moment it's cast — never stored as plaintext
① Key Generation (once per election)
prime p = 2048-bit FFDHE
generator g = standard group gen.
private key x = random secret
public key h = gx mod p
② Encryption (at vote time)
vote m = candidate index
random r = fresh each vote
C1 = gr mod p
C2 = m × hr mod p
③ What's stored in the DB
C1 = opaque integer
C2 = opaque integer
