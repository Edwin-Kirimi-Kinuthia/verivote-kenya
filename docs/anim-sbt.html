Soul Bound Token (SBT)
Non-transferable on-chain identity — permanently bound to one voter
✅ Minted on registration
Voter passes KYC → IEBC approves → SBT.mint(wallet, tokenId) called on-chain. Bound to voter's address — cannot be sent or sold.
❌ Transfer blocked
Any transferFrom() call reverts. Transfer functions are disabled at the Solidity contract level.
🔥 Revoked if deceased
Admin marks DECEASED → SBT.revoke(tokenId) burns token on-chain → sbtRevokedAt recorded → authentication permanently blocked.
