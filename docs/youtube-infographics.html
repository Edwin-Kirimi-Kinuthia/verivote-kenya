02 / 08 — Soul Bound Token (SBT)

⛓️ Soul Bound Token

Your identity, permanently bound to the blockchain. Non-transferable by design.

✅
1. Voter Registers
KYC via Persona ID verification. Biometric captured. National ID validated against IEBC register.
🔷
2. SBT Minted
Smart contract mints a non-transferable ERC-721 token to the voter's wallet address. Token ID recorded in database.
SoulBoundToken.mint(walletAddress, tokenId)
tx: 0x4f3a...d8c2 ✓ confirmed
🗳️
3. SBT Checked at Vote Time
Voter cannot cast ballot without a valid, unrevoked SBT. Prevents impersonation and double-voting.
🔥
4. SBT Revoked (if deceased)
Admin marks voter DECEASED → system calls revokeSBT(tokenId) on-chain → token burned → identity permanently blocked.
status: DECEASED
deceasedAt: 2027-08-09T14:32:00Z
sbtRevokedAt: 2027-08-09T14:32:01Z
Why Non-Transferable?
A transferable identity token could be sold or stolen. Soul Bound means the token is technically locked to one address — transfer functions are disabled at the contract level. Attempting to transfer throws a revert.
Ghost Voting Prevention
In traditional systems, deceased voters can be fraudulently used. In VeriVote, the IEBC can burn the on-chain token within seconds of receiving a death certificate. The blockchain records the revocation permanently.

03 / 08 — Authentication & Distress PIN

🔐 WebAuthn + Distress PIN

Passwordless biometric login with a hidden coercion signal.

👆
WebAuthn
Voter authenticates with their device's fingerprint, face ID, or security key. No passwords. No phishing. Cryptographic challenge-response backed by hardware.
🔢
Normal PIN
User-chosen 4-digit PIN confirmed at vote cast time. Stored as argon2id hash. Validates: not all-same (1111), not sequential (1234/4321).
🆘
Distress PIN
Server-generated 4-digit code sent privately to voter's phone. If entered instead of normal PIN — vote appears successful but is silently flagged. Coercer sees nothing.
⚠️ DISTRESS SCENARIO
A voter is being coerced to vote for Candidate A. They enter their distress PIN instead of their normal PIN.

What the coercer sees: "Vote cast successfully ✓"
What happens silently: isDistressFlagged = true recorded on vote. AI fraud score elevated. IEBC security team alerted.
✅ NORMAL SCENARIO
Voter authenticates with biometric → selects candidate → confirms with normal PIN → vote encrypted and cast. No flags. No alerts. Clean audit trail.

➕ Homomorphic Tally

Count 1 million votes without reading a single one.

The Key Property of ElGamal
Multiply ciphertexts = Encrypt the sum
Enc(a) × Enc(b) = Enc(a + b)

// Without decrypting a or b individually!

06 / 08 — Shamir's Secret Sharing

🗝️ Shamir's Secret Sharing

No single person holds the decryption key. The result requires cooperation.

The (k, n) Threshold Scheme
The election private key is split into n = 5 shares.
Any k = 3 shares reconstruct the key.
Fewer than 3 shares reveal nothing about the key.
Polynomial of degree k-1
f(x) = secret + a₁x + a₂x²

share₁ = f(1), share₂ = f(2) ... share₅ = f(5)
